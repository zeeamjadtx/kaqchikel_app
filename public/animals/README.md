# Animal celebration drawings

Place each drawing here as **PNG** (transparent background works best).  
When a student matches or flips that animal in **Animales Salvajes**, it dances with a motion styled for that species.

| File | Kaqchikel term | Dance style |
|------|----------------|-------------|
| `koj.png` | Köj (león) | Proud bounce (lion) |
| `balam.png` | B'alam (tigre) | Quick pounce |
| `utiw.png` | Utiw (coyote) | Zigzag hop |
| `nimaqul.png` | Nimaq'ul (cocodrilo) | Side sway |
| `tix.png` | Tix (elefante) | Heavy stomp |
| `ixpach.png` | Ixpa'ch (lagartija) | Fast dart |
| `oxox.png` | Oxox (oso) | Slow sway |
| `par.png` | Par (zorillo) | Waddle |
| `batz.png` | B'atz' (mono) | Bouncy |
| `koy.png` | K'oy (mico) | Bouncy |
| `kumatz.png` | Kumatz (serpiente) | Slither |
| `masat.png` | Masat (venado) | Light hop |

Only animals with a file in this folder will show the celebration.
