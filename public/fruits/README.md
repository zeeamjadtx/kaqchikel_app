# Fruit celebration drawings

Add a PNG for each fruit you want to animate in the **Frutas** deck.
Same celebration popup as Animales Salvajes (matching game + flashcards).

| File | Spanish term | Kaqchikel |
|------|--------------|-----------|
| `coco.png` | Coco | Wachxan |
| `banano.png` | Banano | Saq'ul |
| `durazno.png` | Durazno | Tur'as |
| `limon.png` | Limón | Limonix |
| `pina.png` | Piña | Ch'op |
| `melon.png` | Melón | Q'anaq'oq' |
| `aguacate.png` | Aguacate | Oj |
| `papaya.png` | Papaya | Kaqrab' |
| `manzana.png` | Manzana | Nimamixku |
| `mango.png` | Mango | Q'anatz'ub' |
| `anona.png` | Anona | Päk |
| `naranja.png` | Naranja | Arañazo |
| `fresa.png` | Fresa | Saqatokan |
| `sandia.png` | Sandía | Kaqaq'oq' |

Only fruits with a file here will show the dance. You can add just some, like with the animal deck.

**Note:** Plátano (Nimasaq'ul) does not use a celebration image — use `banano.png` for **Banano** (Saq'ul).
